# Muttaqi Hajj & Consultancy (মুত্তাকী হজ্ব ও কন্সাল্টেন্সি)

A modern, responsive, high-performance React application rewritten for **Muttaqi Hajj & Consultancy**, the leading provider of Hajj & Umrah services, international visa processing, air ticketing, hotel reservations, passport assistance, and manpower consultancy based in Dupchanchia, Bogura, Bangladesh.

## Core Features & Functionality

- **Hero & Spiritual Dua**: Featured Arabic prayer (*اَللَّهُـمَّ افْتَـحْ لِي أَবْوَابَ رَحْمَتـِكَ*) alongside trusted pilgrimage consultation highlights.
- **5 Pillars of Islam (ইসলামের ৫টি স্তম্ভ)**: Interactive pillar guide with explanations for Iman, Salah, Zakat, Sawm, and Hajj.
- **Prayer Times Schedule (আজকের নামাজের সময়সূচী)**: Daily prayer times for Bogura/Bangladesh with real-time indicators.
- **Comprehensive Services Catalog**:
  - Hajj & Umrah Packages (হজ্ব ও ওমরাহ সেবা)
  - Air Ticketing & Global Hotel Reservations (বিমান টিকিট ও হোটেল বুকিং)
  - Tour Packages (ভ্রমণ প্যাকেজ সেবা)
  - Worldwide Visa Processing (সব দেশের ভিসা প্রক্রিয়াকরণ)
  - Passport Processing (পাসপোর্ট প্রক্রিয়াকরণ)
  - Manpower & HR Services (মানবসম্পদ সেবা)
  - Immigration Assistance (ইমিগ্রেশন সহায়তা)
- **Interactive Package Calculator**: Estimate and customize pilgrimage duration, hotel tier, and group configuration with 1-click quotation submission.
- **Photo Gallery & Lightbox**: High-resolution gallery of holy sites (Makkah al-Mukarramah, Madinah al-Munawwarah), pilgrim groups, and seminars with category filters and modal viewer.
- **Leadership & About Us**: Profile of Founder মোঃ রাজু মিয়া and the 7 Managing Directors, company track record (5+ Hajj, 10+ Umrah, 150+ Air Tickets, 100+ Tours), and mission statement.
- **Direct Contact & Verification**:
  - Direct Phone Hotline: (+88) 01768-232501 / 01746-900513
  - Office Address: A-16, Madina Shopping Complex, Dupchanchia, Bogura, Bangladesh
  - Interactive Contact Form with validation and real-time confirmation
  - Embedded Google Map with exact location coordinates
  - Floating 1-click WhatsApp and Phone dialer buttons
- **SEO & Structured Data**: Complete OpenGraph, Twitter Card, geo coordinates, and Schema.org `TravelAgency` JSON-LD structured data.

## Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS with custom Islamic gold palette (`#DCB473`)
- **Icons**: Lucide React + custom SVG brand icons
- **Fonts**: Google Fonts (Noto Sans Bengali, Hind Siliguri, Amiri)

## Development

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Production build
npm run build
```
